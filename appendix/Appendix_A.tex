\section{Evaluation Protocol}
\label{app:eval-protocol}

\subsection{Dataset Construction}
\label{app:eval-dataset}

Each benchmark dataset in LLMWikiBench follows this construction protocol:

\begin{enumerate}
  \item \textbf{Corpus Selection}: Curated real-world repositories (GitHub, documentation sites, API registries) with permissive licenses.
  \item \question{Question Generation}:
    \begin{itemize}
      \item Template-based: Parameterized templates for common patterns (e.g., "How does X call Y?")
      \item LLM-assisted: Local LLM generates diverse question variations
      \item Human review: All questions reviewed for clarity and answerability
    \end{itemize}
  \item \textbf{Ground Truth Answers}: Written by domain experts, verified against source corpus.
  \item \textbf{Evidence Annotation}: Experts mark exact unit spans (by SHA-256 ID) supporting each answer.
  \item \textbf{Quality Control}: Inter-annotator agreement (Cohen $\kappa > 0.8$) on 10\% sample.
\end{enumerate}

\subsection{Metrics Computation}
\label{app:eval-metrics}

\begin{algorithm}[H]
\caption{Evidence Recall@k}
\label{alg:ev-recall}
\begin{algorithmic}[1]
\Require $Q$: queries, $\mathcal{E}^*(q)$: ground-truth evidence IDs, $\mathcal{E}_k(q)$: gate-verified top-$k$
\Ensure $\text{EvRecall}@k$
\State $sum \gets 0$
\ForEach{$q \in Q$}
  \State $common \gets |\mathcal{E}^*(q) \cap \mathcal{E}_k(q)|$
  \State $sum \gets sum + \frac{common}{|\mathcal{E}^*(q)|}$
\EndFor
\State \Return $\frac{sum}{|Q|}$
\end{algorithmic}
\end{algorithm}

Attribution Score uses a fine-tuned NLI model (BART-large-MNLI) to check if each claim $c$ in answer is entailed by cited evidence $e$:
$\text{Attribution}(a) = \frac{1}{|claims(a)|} \sum_{c \in claims(a)} \mathbb{1}[\text{NLI}(e_c, c) = \text{Entailment}]$

Hallucination Rate: $\frac{1}{|claims(a)|} \sum_c \mathbb{1}[\text{NLI}(e_c, c) = \text{Contradiction} \lor \neg \exists e_c]$

\subsection{Statistical Rigor}
\label{app:eval-stats}

All reported metrics include:
\begin{itemize}
  \item 95\% Bootstrap confidence intervals (1000 resamples)
  \item Paired Wilcoxon signed-rank test for pairwise comparisons ($p < 0.05$)
  \item Benjamini-Hochberg FDR correction for multiple comparisons
  \item Cohen $d$ effect sizes
\end{itemize}

Regression gate: CI pipeline fails if any primary metric (Evidence F1, Attribution, Hallucination) degrades by $> 2\%$ absolute vs. \texttt{main} branch baseline.
