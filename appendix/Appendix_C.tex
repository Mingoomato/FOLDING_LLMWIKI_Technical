\section{Environment Variable Overrides}
All configuration keys can be overridden via environment variables:
\begin{verbatim}
LLMWIKI_<SECTION>_<KEY>=value
\end{verbatim}
Example: \texttt{LLMWIKI\_INGESTION\_EMBEDDER\_MODEL=bge-m3}
